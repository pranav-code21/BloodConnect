# BloodConnect – Blood Donor Finder

BloodConnect is a web-based application that helps users find blood donors based on blood group and location.

## Features
- Search blood donors by blood group and city
- Register as a blood donor
- Update donor availability
- View donor statistics
- Submit emergency blood requests

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Requirements
- Node.js and npm
- MySQL Server

## Installation and Setup
1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Create the MySQL database named `EBDF` and configure the required tables.
5. Create a `.env` file using your local database credentials.
6. Start the server:

   ```bash
   node server.js
   ```

7. Open the local website using the address configured in the project.

## Note
This project is intended for local development. Online deployment requires additional server and database configuration.
